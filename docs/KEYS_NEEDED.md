# PropBot Pro — Environment Variables & Integrations Directory (`KEYS_NEEDED.md`)

This directory documents every environment variable and credential used across PropBot Pro.  
**Rule**: Never commit, log, echo, or share secrets. Keep `.env.example` strictly in sync with safe placeholders only.

---

## 1. Required Platform Core (Tier A)

These variables are required for the application server and background worker to boot.

| Variable Name | Plain-English Meaning | Where to Get It | Required Now? | Phase Introduced |
| :--- | :--- | :--- | :--- | :--- |
| `NODE_ENV` | Runtime environment (`development`, `test`, `production`) | Local configuration | **Yes** | Phase 1 |
| `PORT` | HTTP port on which the Express API server listens (default: `3000`) | Local configuration | **Yes** | Phase 1 |
| `DATABASE_URL` | PostgreSQL 16 connection string (with `pgvector` enabled) | Local Postgres or hosted DB (e.g. Render / Neon / Supabase) | **Yes** | Phase 1 |
| `REDIS_URL` | Redis 7 connection URL for BullMQ queues and jobs | Local Redis or hosted Redis (e.g. Upstash / Render) | **Yes** (or local default) | Phase 1 |
| `JWT_ACCESS_SECRET` | 64-character secret for signing short-lived JWT access tokens | Generated via `pnpm setup:keys` or `openssl rand -hex 32` | **Yes** | Phase 1 |
| `JWT_REFRESH_SECRET` | 64-character secret for rotating refresh tokens | Generated via `pnpm setup:keys` or `openssl rand -hex 32` | **Yes** | Phase 1 |
| `ENCRYPTION_KEY` | 32-byte hexadecimal key for AES-256-GCM credential vault | Generated via `pnpm setup:keys` or `openssl rand -hex 32` | **Yes** | Phase R3 |

## 4. How to Configure Locally

Run the interactive setup wizard in your terminal:
```bash
pnpm setup:keys
```
The wizard will:
1. Auto-generate all required platform secrets (`JWT_ACCESS_SECRET`, `JWT_REFRESH_SECRET`, `ENCRYPTION_KEY`, and `WHATSAPP_VERIFY_TOKEN`).
2. Ask only for keys relevant to your chosen LLM and channel setup.
3. Validate keys with live lightweight test calls without ever printing secrets to the screen.
4. Merge updates safely into your local `.env`.
